Which slice each bit of x lands in

Each colored band is one slice's window: α = 53 − β bit positions below that pass's leading bit. The next window starts at the leading bit of what's left, which can be a few positions below the cut: when x's bits there are 0s, or when rounding up turned them into a carry. Bits in such a gap get the color of the slice above, which absorbed them.

Slice count vs exponent span

Each window holds α bits, so covering a span plus one element's 53 bits takes at most ⌈(span + 53) / α⌉ slices (dashed). When the gaps between neighbouring elements are wider than a window, σ jumps straight to the next element's leading bit and the empty exponents cost nothing, so few elements over a wide span need fewer slices.
