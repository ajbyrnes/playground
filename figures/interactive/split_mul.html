Split_Mat(A): splitting a matrix by rows

matrix A
bits per slice

A = D(1) + D(2) + …

Darker cells in A have larger exponents; colored cells in D(k) are nonzero. Large entries are used up in the first slices, small ones start in later slices.

Which slice each bit of A lands in

Each cell is one entry's 53 significand bits (leading bit on the left, solid = 1, faded = 0), colored by the slice that holds them. Each row has its own σ, so each row is split exactly like split_vector, with its own windows of α bits. Row i needs Ki slices; A needs K = max Ki, and rows that finish early are zero in the later D(k).

Slice count vs widest row span

Shifting a whole row up or down changes nothing, because σ follows the row's max. Only the span inside a row costs slices, so the widest row sets K.
