# WCP presentation materials

Slides and figures for the WCP talk on the Ozaki scheme / DGEMM emulation.

- `slides/` — Quarto reveal.js deck (`quarto preview slides/slides.qmd`)
- `figures/interactive/` — standalone HTML figures (open directly in a browser, or embed in slides)
- `figures/static/` — PDF figures, generated by `figures/scripts/figures.py`
- `figures/scripts/` — Python that generates the figures
- `notes/` — talk outline and notes
- `papers/` — reference papers (gitignored)
